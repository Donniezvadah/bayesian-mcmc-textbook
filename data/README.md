# Data

No data files are stored in this repository. Every real data set used in the book is either

- distributed with R (packages `datasets`, `MASS`, `boot`) and loaded in the code, or
- a small published table reproduced in the code with its source cited (the bioassay data, the eight-schools estimates, Kerrich's coin total).

Provenance, licences, variables, missing values and preprocessing for each data set are documented in Appendix C (`appendices/datasets.qmd`). If you add a data file here, add a provenance entry there, including the source, licence and any preprocessing.
